## 세부 작업 내용

### 지원자 비교와 작업자 선택

- 의뢰인이 업무 상세 화면에서 지원자의 프로필과 정보를 비교할 수 있는 전용 화면을 구현했다.
- 비교 기능을 업무 등록자에게만 노출하고, 공개 GNB에서는 제거해 권한 범위를 분리했다.
- 지원, 지원 취소, 작업자 선택 흐름을 구현하고 취소된 지원자는 목록에서 제외했다.
- 이미 처리된 지원을 다시 요청해도 중복 처리되지 않도록 재지원 흐름을 보완했다.

### 업무 취소·정산·내 업무 화면

- 매칭 전·후 의뢰인 취소를 지원하고, 업무 만료 시 예약된 품이 자동 반환되도록 처리했다.
- 품 거래 이력을 프로필에서 확인하도록 연결했다.
- 작성한 업무의 상세 화면 이동, 내 업무 대시보드 이동, 진행상황 메뉴 분리 등 업무 탐색 흐름을 개선했다.

### 리뷰와 업무 정보 UX

- 프로필에 작성한 리뷰와 받은 리뷰를 구분해 표시하고, 공개 프로필에서도 받은 리뷰를 볼 수 있게 했다.
- 긴 리뷰를 접고 펼칠 수 있는 더보기 UI를 구현했다.
- 업무의 외부 참고 링크와 첨부 파일을 별도 필드로 분리해 정보 성격을 명확히 했다.

### 로그인·배포·안정화

- 카카오와 구글 소셜 로그인을 연동하고, OAuth 계정 정보를 관리하도록 구현했다.
- Render 배포 환경을 위한 Dockerfile, 배포 설정, Docker 제외 목록을 추가했다.
- 권한 없는 관리자 접근 시 사용자 안내를 제공했다.
- 전역 오류 처리 화면을 만들고, 채팅·업무·지원자 목록 조회 쿼리를 개선했다.
- WebSocket 메시지가 인증된 사용자에게만 전달되도록 보완하고, AI 설정 누락·클라이언트 생성 문제도 방어했다.

### 문서화와 테스트

- 사용자 취소, AI·포트 충돌, WebSocket 동작 관련 트러블슈팅 문서를 작성했다.
- 완료 업무 정산 화면과 참고 링크·파일 분리, 채팅 흐름 변경에 맞춰 테스트를 보완했다.
