## 4. 의존 관계

```text
회원·인증
  ├─ 프로필
  ├─ 품 계정·거래 원장
  └─ 업무 등록·지원
       ├─ 작업자 선택
       │    ├─ 업무 진행·결과 제출
       │    └─ 업무별 채팅
       ├─ 완료 승인·품 정산
       └─ 분쟁
            └─ 관리자 처리·감사 로그

DB 스키마·Storage
  └─ 모든 서버 기능의 선행 기반

자동 테스트
  └─ 각 기능 완료와 병합 전 공통 완료 조건
```

## 5. 협업 완료 조건

각 작업은 다음 조건을 충족했을 때 `DONE`으로 변경합니다.

- 요구사항과 허용 상태 전이가 코드에 반영되어 있다.
- 입력값, 소유권과 역할 권한을 검증한다.
- DB 변경은 새 Flyway 파일로 작성하고 기존 적용 파일을 임의 수정하지 않는다.
- 정상 흐름과 주요 실패 흐름 테스트를 작성한다.
- `./gradlew test`가 통과한다.
- PR에 변경 목적, 영향 범위, 테스트 결과와 DB 변경 여부를 기록한다.
- 최소 한 명의 리뷰 후 병합한다.
